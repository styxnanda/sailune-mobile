# Sailune Android v1.0.0

- Centered Sailune icon and name in Settings, with the version number underneath.
- Compact, expanding personal and website tag fields in collection search, with a clean borderless filter section.
- Stories already in a collection are checked and locked in the add view. Use View collection to select stories for removal.
- FanFiction.net fetching and refresh are disabled until signed in through Settings. The welcome tour explains that signing in improves scraping reliability.
- Swipe left from Library to Collections and right to return. Existing story status gestures remain available.
- Title and author fields are disabled while fetching website details, and manual values are excluded from fetched additions.

Version 1.0.0, Android build 15. The shared core remains v0.9.0, with existing databases and ZIP backups compatible.

The APK supports ARM64 and x86_64 and remains development-signed. CI signing keys can differ from previously installed builds. Export and verify a backup before uninstalling or switching builds if Android rejects the signing key.
